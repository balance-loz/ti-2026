# TI 2026 Predictor

Живой вероятностный прогноз всего The International 2026: личные оценки, статистическая модель, Монте-Карло, швейцарка, стыки, плей-офф и честная оценка каждого матча.

## Что умеет модель

- соблюдает раскрытый формат TI 2026: в первых трёх раундах команды встречаются только внутри групп A/Б, а в четвёртом и пятом группы объединяются;
- проверяет одну контрольную карту состава на каждом турнире;
- учитывает составы 5/5, 4/5 и 3/5 с весами `1.00`, `0.25`, `0.07`;
- сильнее взвешивает свежие матчи (полураспад 45 дней, выбран walk-forward проверкой на 419 сериях);
- объединяет карты в серии и не считает 2:0 двумя независимыми матчами;
- строит Bradley–Terry-рейтинг через общих соперников и регуляризованный H2H;
- передаёт в Монте-Карло неопределённость рейтинга и единую форму команды на турнире;
- смешивает статистику с мнением пользователя ручным ползунком;
- фиксирует сыгранные матчи TI, исключает невозможные ветки и сильно обновляет текущую форму;
- сохраняет вероятность до матча и показывает, был ли прогноз верным.
- автоматически читает опубликованные будущие пары с Cybersport.ru и замораживает pre-match вероятность до результата;
- оценивает каждый матч отдельно и по стадиям: accuracy, Brier score и log loss;
- хранит неизменяемую историю прогонов с Brier score и log loss после появления результатов;
- раскладывает каждый матч-прогноз на вклад общих соперников, H2H, состава, мнения и текущего TI;
- показывает примерное число уникальных полных путей и долю повторов Монте-Карло.
- строит одну конкретную вероятнейшую сетку всех пяти раундов и предварительный double-elimination плей-офф;
- сохраняет серверные снимки до раунда и после каждого нового результата, даже если браузер администратора закрыт;
- использует локальные логотипы участников, полученные со страниц команд [Cybersport.ru](https://www.cybersport.ru/tournaments/dota-2/the-international-2026).

Повторы сеток в Монте-Карло намеренны: более вероятная ветка должна встретиться чаще, иначе её частота перестанет быть оценкой вероятности. Для худшего случая 100 000 прогонов дают около ±0,31 п.п. 95%-й погрешности, 250 000 — около ±0,20 п.п. После фиксации сыгранных матчей пространство веток сужается автоматически, но нужное число прогонов определяется требуемой погрешностью, а не числом уникальных сеток.

## Следующий слой: прогноз карты после драфта

Его следует обучать отдельно от предматчевой модели. Текущая вероятность серии становится prior, а patch/draft-модель обновляет шанс конкретной карты по десяти героям, Radiant/Dire, порядку пиков, игрокам на героях и взаимодействиям героев. Так прогноз до драфта остаётся стабильным и объяснимым, а данные текущей меты не подменяют силу команды.

## Локальный запуск

```bash
npm ci
npm run dev
```

Для полного серверного режима в другом терминале:

```bash
set ADMIN_PASSWORD=длинный-случайный-пароль
npm run api
```

Dev-сервер интерфейса не проксирует API автоматически; полноценный same-origin режим проще проверять через Docker Compose.

## Развёртывание на VPS по IP

Полная пошаговая инструкция для чистого Ubuntu-сервера: [docs/UBUNTU_DEPLOY.md](docs/UBUNTU_DEPLOY.md).

Установите Docker и Git, затем:

```bash
git clone https://github.com/balance-loz/ti-2026.git
cd ti-2026
cp .env.example .env
nano .env
docker compose up -d --build
```

После этого сайт откроется по `http://IP_СЕРВЕРА/`. SQLite, кэш OpenDota и свежий JSON статистики лежат в Docker volumes и не пропадают после обновления контейнера.

Важно: пароль через обычный публичный HTTP можно перехватить. Для админ-входа без домена рекомендуется заходить на сервер через приватную сеть Tailscale/WireGuard либо настроить HTTPS с доверенным сертификатом. Пока HTTPS нет, используйте длинный уникальный пароль и не входите в админку через чужой Wi‑Fi. При HTTPS поставьте `COOKIE_SECURE=true`.

Обновление:

```bash
git pull
docker compose up -d --build
```

## Команды

- `npm run build` — production-сборка;
- `npm run stats:update` — осторожное обновление кэша OpenDota;
- `npm run model:backtest` — walk-forward проверка вариантов полураспада без подглядывания в будущее;
- `npm run api` — API, SQLite и админ-сессии.

Секреты не коммитятся: `.env` исключён из Git, в репозитории есть только `.env.example`.
