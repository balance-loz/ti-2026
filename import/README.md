# Каталог импорта

Положите сюда `.sqlite` архив прошлых матчей — сервер сам его найдёт, разберёт
и переобучится в течение 10 минут. Никаких команд запускать не нужно.

Можно класть файл в любой момент: до первого запуска контейнеров или после.

Проверить, что файл замечен:

    docker compose exec api node scripts/predictor.mjs status

Разобрать немедленно, не дожидаясь планировщика:

    docker compose exec api node scripts/predictor.mjs import

Каждый файл импортируется ровно один раз. Замените его другим — он будет
обработан как новый. Архив с непонятной схемой отклоняется целиком.
